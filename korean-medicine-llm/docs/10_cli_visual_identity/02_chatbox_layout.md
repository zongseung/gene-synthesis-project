## 1. PNG → ASCII 자동 변환 결과

생성 스크립트: `/tmp/png2ascii.py` (Pillow 기반 luminance sampling, density ramp `"@#8%*+o=-:. "`).

아래가 **50-col / 28-row** 렌더링. 원본 픽셀 아트의 거북 머리·약사복·약연 그릇·우측 꿀단지·상단 매달린 약재 3개 모두 식별 가능.

```
   ....:=-..                     ..-o.. .==. .
     ..=-..                      ...o...  ==.
   ...:=-...                       -o..   == .
      :=-                     . -=:=o:-=. ==..
   +*+++++o. .    .............-o%*+%+=.. ==..
   ++o++o+o..   .............. .+%++++**. ==..
   ==-oo=.        :++***++**.   *8++++%8..=oo=.
   =o=o+=-:.....:*%o++oo++oo%+::-***%o:---+o---
   ooo==ooo. . =@o----+=::=+=+@- ....  =o-++-o=
          . ...o@o---=*+oo++-+@-..    .oo=++=o=
   ... .--=8###88*+o=-:=+oo=--:...... .--:==:--
      =*###88888%o==o+o==+o=o-.
  ..=88#888888%+--:.:-+**-:.=o+:. ...:::.
 . .#@@8%8##8%%-:..:+:..o%:::--.++ .:-:.
 .  #@%88%##8%*-:..-8*o.-o:=*#8+%+ ....::::..
 .  #@%8888#8%*-:.o*+88---%8@@#88*.   ..::-.
 .  #@888#8%8%%+oo#8--=@%=oo=ooo@# ...::-:....
 .  @@888#888%%=--=o%%%+=:---o*#8+....-o==o==o
 . .*888%%888%*==-..::-oo+==+:::-o8+= .:o=:==:
   . =@@##88@@#++++++ooo+*ooo++o8@@@#o++8+.%8+
   ...::-:*88##*o:==o++*++++o===@@:+8@@8=o%888
              .+*%%%%@@++*@#%%%%*o  .+8@@@@@@
     ......   . .=====-   ======. ..  :=====
```

- **해석**:
  - 상단 `:=`·`==` 세 블록 = 매달린 약초 3묶음 + 끈
  - 중앙 `##` 둥근 덩어리 = 거북 머리(왼쪽 등껍질과 연결된 라운드)
  - `@@` 밀집부 = 얼굴·눈·입 (눈 `o`, 코 `▼`이 `@o---=*+oo++-+@` 로 표현됨)
  - `888%##` 중앙 밀집 = 약사복 + 양 팔의 약연 그릇 테두리
  - 우측 `=o`·`o8`·`:=====` 세로 줄 = **김 + 꿀단지**. 상단 `~~~` 대신 density char 로 자연 형성
  - 하단 `=====` = 바닥 그림자
- **폭**: 실제 최대 line width 48 col. 80-col 터미널에 충분히 여유.
- **높이**: 28 line. 24-row 터미널에서 splash 만 단독 출력 시 스크롤 없이 보이려면 뒤의 banner/chat 를 짧게 잡아야 함 (§3 참조).
- **압축 버전 (36 col)**: `/tmp/turtle_36.txt` 저장됨 — 작은 창용 fallback. 원화 인식률은 소폭 떨어짐.

## 2. 채팅 박스 레이아웃

사용자 요구 구조:
```
-------------------------
(채팅이 이 안에 들어감)
-------------------------
```

채팅 zone 은 **두 개의 가로 구분선**으로 감싸고, 그 안에 `[you] / [dongui]` 턴이 순차 쌓임. 위쪽에는 mascot+banner, 아래쪽에는 input prompt 가 붙는다.

### 2.1 가로 구분선 선택지

| 스타일 | 예시 | 특징 |
|---|---|---|
| A. 순수 hyphen | `--------------------------------------------------------------------------` | ASCII-only, 모든 터미널 호환 |
| B. box-drawing 단선 | `────────────────────────────────────────────────────────────────────────` | 유니코드 세련됨. 일부 폰트에서 간격 이슈 |
| C. 양끝 장식 | `◇─────────────────────────── chat ───────────────────────────◇` | 중앙 라벨 가능 |

**권장**: 기본 **A** (hyphen 74 개 = 74 col). `--plain` 아닌 TTY 에서만 **B** 로 업그레이드.

### 2.2 chat zone 최소 높이

한 턴 = `[you] …` 1 line + `[dongui] …` 가변 (n lines). 초기 splash 직후에는 빈 zone 으로 시작하고, 첫 질문 후부터 채움.

```
── chat ─────────────────────────────────────────────────────────────── ▼

  [you] 동의보감 저자는?

  [dongui] 『東醫寶鑑』은 조선 선조의 명을 받아 어의 허준(許浚)이 1596년 착수해
  1610년 완성하고 1613년에 간행한 종합 의서이다. 내경·외형·잡병·탕액·침구 다섯
  편으로 구성되어 있다.

──────────────────────────────────────────────────────────────────── ▲

  [you] ▍
```

## 4. Prompt label 재검토

구분선이 도입되므로 label 이 아래 chat 안에서 시각 앵커 역할. 기존 `[you]` / `[dongui]` 유지하되 색상은:

- `[you]` → cheek-rose `#e99b99`
- `[dongui]` → body-green `#8fbd6e`
- `[dongui:error]` → red fallback `#d05555`
- 구분선 `----` → steam-gray `#cfcfcf`

비 TTY / `--plain` 시 전부 무색.

## 5. 구현 계획 (branding.py 수정 항목 — 01 문서 §8 업데이트)

1. **신규 상수**:
   ```python
   MASCOT_TURTLE_FULL = """..."""   # §1 의 50-col 28-line ASCII 전체
   MASCOT_TURTLE_MINI = """..."""   # 36-col 18-line (fallback / 작은창)
   CHAT_DIVIDER = "-" * 74          # §2.2 A
   CHAT_DIVIDER_UNICODE = "─" * 74  # §2.2 B
   INLINE_TITLE = "  D O N G U I  ·  KOREAN MEDICINE AI"
   ```
2. **INTRO_LINES 재작성** (ver4 실측 반영):
   ```python
   INTRO_LINES = (
       "HanMed · 26 books · P-A+ CPT adapter",
       "KIOM mediclassics.kr based training",
       "Not for clinical decision-making",
   )
   ```
3. **SPLASH 합성 함수** (render.py):
   ```python
   def render_splash(first_run: bool, tty: bool) -> str: ...
   ```
   - `first_run=True` → Mascot full + banner + chat-intro (§3.1)
   - `first_run=False and tty` → banner + chat box (§3.2)
   - `--plain` or `not tty` → INLINE_TITLE + INTRO_LINES + CHAT_DIVIDER 만
4. **CLI 플래그 추가** (main.py):
   - `--splash {hero, compact, none}` — 기본 `auto` (seen_splash 파일 존재 판별)
   - `--divider {ascii, unicode, none}` — 기본 `ascii`
   - `--mascot {turtle, cabinet, none}` — 기본 `turtle`. 기존 `MASCOT_CABINET` 은 v1 호환으로 남김

## 7. 열린 결정

- **Mascot 위치**: splash 상단 (§3.1) vs. banner 우측 nested (01 §5 옵션 A) — v2 에서는 **상단 중앙** 권장. nested 는 80-col 초과 위험.
- **구분선 길이**: 74 vs 76 vs 78. 현 제안 74 (양쪽 3 col 여백).
- **Mascot 재출력**: `/reset` 명령 시 다시 full splash 를 띄울지, compact 으로 돌릴지.
- **컬러**: 8색 vs 256색. 기본은 8색 fallback + `--color 256` 플래그로 업그레이드.
