# ADR-0001 · 독성 충돌 시 자동 링크를 보류한다

날짜 2026-07-27 · 상태 **일부 대체됨** → [ADR-0002](0002-reading-links-are-recorded-not-served.md)

> 2026-07-28 개정: 독음 링크 27종을 전수 검사하니 오류율이 26%였고, 그 7종 모두
> `tox_status=unverified` 라 아래의 독성 충돌 필터를 통과했다. 독음 링크는 이제
> 충돌 여부와 무관하게 게이트에서 제외한다. 독성 충돌 표시(8종)는 그대로 유지한다.

## 맥락

종 ↔ 한자 표제어 링크를 한자 독음 대조로 자동 확장했다(80종 → 107종). 확장 직후
실측에서 다음이 나왔다.

```
독미나리 (Cicuta virosa, 맹독)  →  水芹 (미나리)  →  동의보감 「무독」
```

독미나리는 한국 산나물 중독사고 대표종이다. 자동 링크가 성립하는 순간 이 종은
「무독」이라는 고전 근거를 정상적으로 조회하게 되고, 게이트 1단은 출처(권·seq)까지
붙여 통과시킨다. **출처가 완벽하게 붙은 치명적 오답**이 만들어진다.

같은 조건을 전수 검사하니 링크된 종 중 8건에서 「주석은 toxic, 고전은 무독」 충돌이
나왔다. 그런데 성격이 둘로 갈렸다.

| 유형 | 예 | 성격 |
|---|---|---|
| 종 동정 오류 | 독미나리 ↔ 水芹 | 아예 다른 식물. 효능·주치 근거도 전부 틀렸다 |
| 문헌 간 실제 이견 | 까마중 ↔ 龍葵 | 같은 식물. 동의보감은 무독, 현대는 solanine 으로 독성 |

두 유형을 자동으로 구별할 방법은 없다. 다만 **어떻게 링크됐는지**는 알 수 있다 —
전자는 이번에 자동 확장된 `reading` 링크였고, 후자는 사람이 확인한 `exact_hanja` 였다.

## 결정

독성 충돌이 있을 때 링크 성립 방식에 따라 다르게 처리한다.

- `reading` (자동 확장) → **링크 보류**. `candidate` 로 강등되어 게이트가 `no_knowledge`
  를 내고 모델은 유보한다.
- `exact_hanja` (사람 확인) → 링크 유지, `tox_conflict` 플래그만 세운다.

그리고 링크 방식과 무관하게: **독성 판정은 `tox_status` 라벨만 답한다.** 고전 본문은
독성 판정의 근거로 쓰지 않으며, 게이트는 충돌 종의 고전 독성 기록을 근거로 내주지 않는다.

## 대안

**전부 보류** — 까마중·능소화·메꽃·박주가리 등 사람이 확인한 링크까지 잃는다.
문헌 간 이견은 이 도메인에서 정상이며, 그것을 이유로 근거를 버리면 남는 게 없다.

**전부 유지하고 경고만** — 독미나리에 「무독」 근거가 출처와 함께 붙는다. 최악의 실패
모드를 정면으로 허용하므로 검토 대상이 아니다.

**학명으로 검증** — 옳은 방향이지만 crosswalk 의 `herb_name` 이 전부 비어 있어(공정서
매핑 미확보) 지금은 실행할 수 없다. 확보되면 이 결정을 다시 볼 것.

## 결과

- 링크 107종 유지, 독미나리·미국까마중은 보류되어 유보로 답한다.
- 근거 커버리지가 2종 줄었다. 맹독종에 대해 **유보는 정답**이므로 손실로 보지 않는다.
- `species.tox_conflict` 로 8건이 드러나 있어 사람이 검토할 목록이 된다.
- 비용: 자동 확장이 늘어날수록 보류도 늘어난다. 공정서 매핑을 확보하면 학명 대조로
  종 동정 오류와 문헌 이견을 실제로 구별할 수 있고, 그때 이 규칙은 완화된다.
